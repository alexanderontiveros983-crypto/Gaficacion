# Lienzo vivo – Galería con p5.js y Canvas
Sitio web estático (HTML, CSS, JS) con ocho dibujos: Rana, Dientes de conejo, ¿Qué hay de cena?, Día nevado soleado, Muñeco de nieve, El sol que explota, Nubes que se separan y Estrella fugaz.
Incluye teoría de canvas y p5.js y una página inspector del DOM. Publicado con GitHub Pages.
