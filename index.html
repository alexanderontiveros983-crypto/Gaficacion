La etiqueta <canvas> y el contexto 2D

<canvas> es un elemento de HTML5 que reserva un rectángulo de píxeles donde JavaScript puede dibujar. Por sí solo no muestra nada: es un lienzo en blanco y transparente. Se define con los atributos width y height (el tamaño real del dibujo en píxeles; el CSS solo lo escala).

<canvas id="lienzo" width="400" height="300">
  Tu navegador no soporta canvas.
</canvas>

Contextos de renderizado

Para dibujar se pide un contexto con getContext(). El contexto es el objeto con los métodos de dibujo:

  • "2d": dibujo bidimensional (formas, texto, imágenes, píxeles). Es el que explica esta página.
  • "webgl" / "webgl2": gráficos 3D acelerados por la GPU.
  • "bitmaprenderer": muestra un ImageBitmap ya creado.

Un mismo canvas solo admite un tipo de contexto: el primero que se pide queda fijo.

Sistema de coordenadas

El origen (0, 0) está en la esquina superior izquierda. La x crece hacia la derecha y la y crece hacia abajo.

Ejemplo en vivo con JavaScript puro (sin p5.js):

const ctx = document.getElementById("demoCanvas").getContext("2d");
ctx.fillStyle = "#3a9d5d";
ctx.fillRect(20, 20, 80, 80);
ctx.beginPath();
ctx.arc(200, 60, 40, 0, Math.PI * 2);
ctx.fillStyle = "#f2a900";
ctx.fill();

Fundamentos de p5.js

p5.js es una librería de JavaScript para programación creativa, inspirada en Processing. Por debajo usa el contexto 2D de <canvas>, pero ofrece funciones más simples, y es la evolución natural de ProcessingJS, que se usa en Khan Academy.

Estructura de un sketch

  • setup(): se ejecuta una vez al inicio. Aquí se crea el lienzo con createCanvas(ancho, alto).
  • draw(): se repite unas 60 veces por segundo; de ahí nace la animación.
  • Eventos: mousePressed(), keyPressed(), etc.

function setup() {
  createCanvas(400, 400);
}
function draw() {
  background(135, 206, 235);
  fill(255, 220, 0);
  ellipse(mouseX, mouseY, 50, 50);
}

Modo instancia

Como esta página tiene cinco dibujos a la vez, cada uno usa el modo instancia: new p5(function(p){ p.setup = ...; p.draw = ...; }, "contenedor"). Así cada sketch tiene su propio lienzo y no choca con los demás, y las funciones se llaman con el prefijo p..

De Khan Academy a la web

Khan Academy usa ProcessingJS: la mayoría de funciones tienen el mismo nombre. Lo que cambia es el entorno: en vez del editor de Khan, ahora hay un archivo HTML que carga la librería con una etiqueta <script> y un archivo .js con los sketches.
